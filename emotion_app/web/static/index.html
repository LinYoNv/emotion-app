    左边选一个会话。

    陪伴插件按这个 ID 认人：记忆 / 关系 / 主动消息开关都挂在它下面， 完整 umo 就是 11:FriendMessage:<它>。 新建会话时自动分配一个独有的，所以可以直接拿它到陪伴面板里 建档、开主动消息。同一个 ID 绑到多个会话时，主动消息只会落到最早建的那个。

    怎么让主动消息落到这个会话（而不是 default）
    1. 确认上面的「插件用户 ID」不是 default —— 老会话会沿用旧的 default（新建会话才会自动分配）， 这时点「换一个专用 umo」即可。
    2. 点「复制 umo」，拿到 11:FriendMessage:<这个 ID>。
    3. 到陪伴插件面板（插件 → 陪伴 → 拓展页）的 用户 / 身份里添加这个 umo， 并给它打开主动消息。

    ⚠️ 插件侧还没有这个用户时，主动消息会落到全局兜底 umo （就是列表里那条「陪伴（主动消息）」会话，绑的是 default）—— 那是回落，不是「只能给 default」。 插件侧建好用户后，之后的主动消息就按这个会话投递。
